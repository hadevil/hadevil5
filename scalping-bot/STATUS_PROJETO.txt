🎯 AS 3 ESTRATÉGIAS
═══════════════════════════════════════════════════════════════

C1 — Breakout Falso (Reversão)
   • TP/SL: 1.8× ATR / 0.8× ATR
   • R/R: 2.25:1
   • Melhor em: Mercados laterais, ranges

C2 — Candle de Expansão (Momentum)
   • TP/SL: 1.4× ATR / 0.6× ATR
   • R/R: 2.33:1
   • Melhor em: Breakouts, tendências iniciais

C4 — Pullback na Tendência (Trend Scalp)
   • TP/SL: 1.0× ATR / 0.5× ATR
   • R/R: 2.0:1
   • Melhor em: Tendências fortes, gráficos 1h

🚀 COMO USAR (QUICK START)
═══════════════════════════════════════════════════════════════

1️⃣  INSTALAR
   cd ~/scalping-bot
   ./install.sh

2️⃣  CONFIGURAR

4️⃣  RODAR
   
   Paper Trading (simulado):
   python main.py --symbol BTCUSDT --strategy C2 --mode paper
   
   Live Trading (REAL):
   python main.py --symbol BTCUSDT --strategy C2 --mode live
